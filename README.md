# Sales_-Analysis_using_Python

## Overview

This project performs sales data analysis using Python. The objective is to analyze sales transactions, clean the dataset, and extract meaningful business insights from the data.

## Features

* Data loading and preprocessing
* Category-wise sales analysis
* Product performance analysis
* Customer purchase analysis
* Exporting filtered data into separate CSV files
* Business insights generation

## Technologies Used

* Python
* Jupyter Notebook
* CSV Files

## Dataset Information

The dataset contains the following attributes:

* Order ID
* Date
* Customer Name
* Product Name
* Category
* Quantity
* Price
